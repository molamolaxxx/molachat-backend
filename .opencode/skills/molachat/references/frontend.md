# MolaChat 前端参考

位于 `src/main/resources/static/`，通过 Thymeleaf 模板渲染。

## 目录结构

| 目录 | 内容 |
|------|------|
| `js/chat/` | 核心聊天逻辑：`user.js`、`session.js`、`message.js`、`chatter.js`、`common.js`、`multichat.js`、`cmd.js`、`history.js` |
| `js/app/` | 应用框架：`main.js`、`remote.js`、`setting.js`、`nav.js`、`lifecycle.js`、`permissions.js` |
| `js/video/` | WebRTC 视频：`rtc.js`、`video.js`、`handler.js` |
| `js/file/` | 文件上传/渲染：`file.js`、`file-dom-render.js` |
| `js/emoji/` | 表情选择器 |
| `js/utils/` | jQuery、Materialize、highlight.js、marked.js、pinchzoom 等 |
